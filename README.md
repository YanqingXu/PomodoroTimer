# 🍅 番茄时钟 - Pomodoro Timer

一个适用于 Windows 10 的精美番茄时钟应用，基于 Electron 构建。

## ✨ 功能特性

- **精准计时**：25分钟专注 + 5分钟短休息，支持自定义时长
- **多种模式**：专注时间、短休息、长休息三种模式
- **任务主题**：点击计时器下方标签即可设置当前工作任务，专注时醒目显示
- **桌面悬浮窗**：最小化到托盘后，桌面保持一个小巧悬浮窗，显示进度条和计时信息，双击即可恢复窗口
- **专注记录**：每次完成番茄钟自动记录任务名称和时长，数据持久化存储
- **系统托盘**：最小化到托盘运行，后台持续计时
- **全局快捷键**：
  - `Ctrl+Shift+P` - 显示/隐藏窗口
  - `Ctrl+Shift+S` - 开始/暂停计时
  - `空格` - 开始/暂停（应用内）
  - `R` - 重置计时器
  - `1/2/3` - 快速切换模式
- **音效提醒**：计时结束播放提示音
- **数据统计**：记录完成的番茄数量和总专注时间
- **连续天数追踪**：帮助你保持每日专注习惯
- **本地存储**：设置和数据自动保存

## 🚀 快速开始

### 方式一：直接运行源码

1. 确保已安装 Node.js (v16+)
2. 安装依赖：
   ```bash
   npm install
   ```
3. 运行应用：
   ```bash
   npm start
   ```

### 方式二：构建可执行文件

```bash
npm run dist
```

构建完成后，可执行文件位于 `dist/` 目录。

## 📁 项目结构

```
pomodoro-timer/
├── main.js              # Electron 主进程
├── preload.js           # 预加载脚本（主窗口安全桥接）
├── index.html           # 主界面
├── styles.css           # 样式表
├── renderer.js          # 渲染进程逻辑
├── overlay.html         # 桌面悬浮窗界面
├── overlay-preload.js   # 悬浮窗预加载脚本
├── package.json         # 项目配置
└── assets/
    └── icon.svg         # 应用图标
```

## 🎨 界面预览

应用采用深色主题设计，番茄红色为主要色调：
- 🎯 专注模式（红色）- 25分钟
- ☕ 短休息（青色）- 5分钟
- 🌴 长休息（紫色）- 15分钟

## ⚙️ 自定义设置

点击"自定义设置"展开选项：
- 专注时长（1-60分钟）
- 短休息时长（1-30分钟）
- 长休息时长（1-60分钟）
- 长休息间隔（2-10个番茄）
- 音效开关
- 自动开始休息
- 悬浮窗透明度（30%-100%）

## 🖥️ 桌面悬浮窗

最小化到系统托盘后，桌面右下角会自动显示一个半透明的悬浮窗，包含：
- 顶部进度条（颜色跟随当前模式）
- 模式图标 + 剩余时间
- 当前任务名称

悬浮窗始终置顶显示，可拖拽移动位置，双击即可恢复主窗口。透明度可在设置中调节。

## 📝 开发说明

### 技术栈
- **Electron 28** - 跨平台桌面应用框架
- **原生 API** - 使用 Web Audio API 播放音效
- **LocalStorage** - 本地数据持久化
- **electron-log** - 日志记录

### 安全说明
- 使用 Context Isolation 隔离渲染进程
- 不启用 Node Integration
- 所有 IPC 通信通过 preload 脚本安全桥接
